# 机会评分口径

每个机会标注四要素：

| 要素 | 是否可算 | 口径 |
|---|---|---|
| 竞争度 | ✅ 可算 | 目标价格带（$50 桶）内 SKU 密度：0-1 低 / 2 中 / ≥3 高 |
| 可解释场景 | ⚠️ 启发式 | 由价格带位置推导（下沿→入门性价比，中段→主流补位，上沿→高端差异化），口径待业务确认 |
| 创新分 | ❌ 需口径 | 评分公式/权重未定义 → `needs_business`，占位 null |
| 契合现有货号 | ❌ 需数据 | 缺现有货号目录 → `needs_business`，占位 null |

## 机会候选生成

- 真空带（分桶计数 0、位于 min~max 之间）
- 稀疏带（分桶计数 1）
- 密集带（≥3）标记为「红海」，不作为补位机会，作为回避提示

## 输出格式

```json
{
  "target_price_band": "$250-300",
  "incumbent_count": 0,
  "创新分": {"value": null, "needs_business": true, "reason": "创新分评分口径未定义，待业务确认"},
  "竞争度": "低",
  "可解释场景": "主流补位（价格带中段）",
  "契合现有货号": {"value": null, "needs_business": true, "reason": "缺少现有货号目录，无法比对"}
}
```
