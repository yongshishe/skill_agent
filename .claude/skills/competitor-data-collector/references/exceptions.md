# 异常处理

| 异常 | 处理 |
|---|---|
| 价格为空 | `price_usd=null`，标脏数据，不进入评分 |
| 销量格式异常 | `sales_estimate=null`，记录原始值到 attributes |
| 反爬 / 登录失效 / 页面结构变化 | 停止重试，记录并转 `needs-developer` |
| 字段缺失 | 置 `null`，由自检脚本统计缺失率 |
| 重复记录（同 `source_url` 或 `sku_id`） | 去重，保留最新 `collected_at` |
| 容量单位混乱 | 优先用 ml/L 精确值；oz 按换算，来源不明确置 null |
| 评分越界（>5 或 <0） | 标脏数据，置 null |
| 样本量 < 5 | 自检标「样本不足」，不阻断但降低置信度 |

## 原则

- 脏数据「标记 + 保留 + 不评分」，不删除、不补造。
- 无法自动解决的异常 → `needs-developer` 工单（字段见工厂 `issue-taxonomy.md`）。
- 能自动修复的（如单位换算、去重）在脚本内处理并写进自检报告。
