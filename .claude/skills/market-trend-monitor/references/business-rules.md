# 趋势监测业务规则

## 三类指标定义

| 指标 | 定义 | 计算方法 |
|---|---|---|
| 价格带迁移 | 竞品价格在 $50 分桶下的分布变化 | 当前期分桶计数 vs 上一期分桶计数；真空带 = 计数为 0 的桶 |
| 功能词热度 | 功能点 / 面料 / 防水 / 容量段的出现频次 | 统计 `filters` 字符串频次 + `attributes` 的 `material_fabric` / `waterproof` / `capacity_l` |
| 品类热度变化 | 各容量段 / 品类的 SKU 数量分布 | 按 `attributes.capacity_l` 分段（20-28 / 35-42 / 45 / 60+）计数 |

## 判定阈值

- 密集带：分桶计数最高的一档（或 ≥ 3 条的档）。
- 真空带：分桶计数为 0、且位于 min~max 之间的档。
- 迁移：两期之间分桶计数差值；单期无迁移结论。

## 边界

- 单期数据 → 只输出「现状」，禁止输出趋势方向。
- 样本 < 5 → 结论置信度低，报告显式标注。
- `price_usd` 为 null 的记录不参与价格分桶，单独计数（`priced_count` vs `record_count`）。
